# FramePlan

Веб-редактор планировок каркасного дома с автогенерацией каркаса по **СП 31-105-2002**, раскроем, сметой и калькулятором теплопотерь.

## Возможности

- 2D-планировка: стены, окна, двери, мебель
- 1 или 2 этажа, типы кровли (двускатная / вальмовая / односкатная / плоская)
- Настройка окон (габариты, высота подоконника)
- Материалы обшивки (наружная / внутренняя / пол)
- Толщина утеплителя отдельно для стен, пола и потолка
- Автоматический каркас: обвязка фундамента, черный пол, стойки/перемычки, перекрытие, кровля
- Проекции, раскрой пиломатериала, сметный лист
- Калькулятор теплопотерь (трансмиссия + вентиляция)

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Примечание

Расчёт каркаса — инженерная модель платформенного каркаса по СП 31-105-2002 (шаг стоек 400/600, двойная верхняя обвязка, королевские/опорные стойки и перемычки проёмов, лежень с анкерами ≤2,4 м). Не заменяет проектную документацию и расчёт конструкций специалистом.
